开放数据接口 · REST API & MCP Server

Free & Public

参考 codex-resets 的开放理念，本平台所有模型降智评测数据全量对开发者和 AI Agent 开放。 您可以将我们的 MCP Server 直接接入 Claude Desktop、Cursor 或 Antigravity，让 AI 随时回答“当前最新哪个模型降智了”。

// Claude Desktop / Cursor / Antigravity MCP Server 配置 (claude_desktop_config.json)
{
  "mcpServers": {
    "model-degradation-watch": {
      "command": "npx",
      "args": [
        "-y",
        "@model-test/mcp-server",
        "--endpoint=https://codex-resets.com/api/v1"
      ]
    }
  }
}

标准 REST 接口规范

GET /api/status 获取全网各模型当前健康状态、降智率与最新事件
GET /api/records 获取全部历史测试战报列表（支持 model, testId, result 过滤）
GET /api/tests 获取所有公开评测题库、Prompt 及判定规范
POST /api/submit 自动化或命令行批量上报测试结果

云端 BaaS 数据库集成 (Supabase / Cloud)

配置免费的 Supabase 项目，即可让全世界的访问者共享同一个在线实时题库与测试看板。未配置时系统将运行在「本地缓存 + 演示同步」模式。
